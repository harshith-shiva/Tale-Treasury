# Tale-Treasury


With the rapid rise of short-form digital content, children are increasingly consuming stories in a passive and fragmented manner, resulting in reduced attention span, limited imagination, and minimal emotional engagement. Traditional storytelling, which encourages reflection, choice-making, and curiosity, is gradually being replaced by fast-paced content that demands little cognitive involvement. This project addresses this challenge by proposing an interactive, AI-driven storytelling web application designed to actively engage children aged 8 to 11 through meaningful narrative participation.
The system enables users to influence the progression of AI-generated stories by making choices at key points in the narrative, allowing each story to evolve dynamically based on the child’s decisions. This interactivity transforms the child from a passive consumer into an active participant, fostering deeper engagement, critical thinking, and emotional connection with the story. A virtual avatar narrator guides the experience, providing contextual narration, encouragement, and emotional feedback to create a warm and human-centered storytelling environment.
TECH STACK:
•	DATABASE: Mongo DB

•	BACKEND: Node.js (Express.js)

•	FRONTEND: React, HTML, Tailwind

•	MODELS: llama 3.1 8B
